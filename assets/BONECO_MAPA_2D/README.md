# BONECO_MAPA_2D

Avatar experimental para o modo mapa 2D lateral.

Pastas principais:
- Falando: videos com alpha para sincronizacao labial.
- Mudo: videos de espera/parado.
- Andando_Direita: ciclos de caminhada para direita.
- Andando_Esquerda: ciclos de caminhada para esquerda.
- Mapas: mapas e assets do cenario 2D.
- metadata/movement: JSON gerado pelo editor de movimento.

Use o painel em `/movement-editor` para processar videos andando com fundo verde.

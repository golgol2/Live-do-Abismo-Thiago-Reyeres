# Convidados especiais

Cada convidado fica em uma pasta propria com esta estrutura:

- `Convidados/NOME/Falando`: videos do convidado falando.
- `Convidados/NOME/Mudo`: videos do convidado em silencio.
- `Convidados/NOME/Voz`: uma voz `.wav`, `.mp3` ou similar para o TTS.
- `Convidados/NOME/config.json`: nome, apelidos e estilo do personagem.

O convidado so entra na live quando tiver voz configurada. Os videos podem ser adicionados depois.
